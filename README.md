# Awesome Maru

![Maru Audio — instruments, effects and musical tools](./MARU_audio.webp)

Selected resources for learning audio, playing instruments and effects, and
building musical tools with Maru.

Explore a sound, try a musical idea, or find a guide for your next project.
Example module pages describe their current controls, access and limitations;
an interactive browser example does not imply an installable DAW plugin.

## About this directory

This directory is curated and published by Maru. It does not accept external
submissions. The examples are a selection; use the linked catalogs for the full
directory. Community projects remain in their authors' repositories.

A listing does not establish audio quality, supported hosts or release
qualification. Each project's documentation owns its requirements and limitations.
Related external references must be MIT licensed and connected to a listed Maru
resource. We credit original authors without porting solicitations or endorsement
claims.

## About Maru
