# Awesome Maru

A community directory of shared resources and open-source instruments, effects,
and tools created with the Maru Engine.

**This repository is a placeholder.** We are preparing the directory and its
contribution process. The categories below are starting points, and there are
no community listings yet.

## What belongs here

- **Getting started:** Engine documentation and module-authoring resources.
- **Learning:** tutorials, worked examples and explanations.
- **Community plugins:** instruments, effects and musical utilities.
- **Reusable resources:** faces, presets, racks, DSP helpers and authoring tools.

Projects should remain in their creators' repositories. This directory links to
their source, credits their authors and describes how to use them. Small shared
guides may live here; plugin implementations and large assets belong with their
own projects.

## Share your work

Read [the contribution guidelines](CONTRIBUTING.md) before opening a pull
request. Community project listings require public source and an explicit
open-source licence. Sharing is voluntary; using the Engine does not require
you to publish your work.

A listing is a discovery link, not a claim of Maru support or qualification.
Each project documents its own dependencies, supported hosts and limitations.
The Engine and third-party dependencies retain their own licences.

## About Maru

Maru builds audio creation tools, instruments and effects. Explore the
[Maru GitHub organisation](https://github.com/maru-audio).
